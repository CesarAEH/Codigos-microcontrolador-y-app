# Contenidos del repositorio
Para la realización del proyecto se usaron codigos para el microcontrolador y para el desarrollo de la aplicación, acontinuación una breve descripción de lo que encontrará en cada carpeta.

**App**:

En esta carpeta encontrará la guia de instalación del desarrollador flutter y la configuración de esta con la aplicación Visual Studio, además de la explicación del código, en un archivo pdf llamado "Guia_flutter (1).pdf", adicionalmente encontrará los códigos utilizados.

**Microcontrolador**:

En esta carpeta encontrará la guia de instalación de un copilador para subir el codigo del microcontrolador, además de la explicación del código utilizado en un archivo llamado "Guia_código_microcontrolador.pdf", adicionalemente encontrará el código utilizado.
